
= Формат книги

Книга упакована внутри исполняемого файла mao-book.exe (написан на Delphi 6, TWebBrowser над движком mshtml.dll). 

Формат - список записей файлов, разделенными тегами:

- #1!# - начало имени файла
- директория (опционально)/имя.расширение, например INDEX.HTML, IMAGES/PIC1.GIF
- 0xb6 признак конца имени
- массив байт, содержимое файла, упакованное библиотекой zlib
- !2!# - признак конца содержимого файла

Скрипт mao_scan.py распаковывает вложенный архив.
